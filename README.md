# Dota Dynasty

Глубокий офлайн-менеджер профессионального киберспорта с полноценной автономной MOBA-симуляцией 5v5 (Windows, Unity 6, C#).

- Спецификация: [`DOTA_DYNASTY_MASTER_SPEC.md`](DOTA_DYNASTY_MASTER_SPEC.md)
- Текущий статус: [`docs/CURRENT_STATUS.md`](docs/CURRENT_STATUS.md)
- Архитектура: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## Сборка и тесты
Требуется .NET SDK 10.
```
dotnet build
dotnet test
```
