# Представление (Dynasty.Presentation + unity/DotaDynasty)

Описывает **реализованное** (этап 04). Спека: §13 (3D Broadcast, Tactical 2D, Analyst View), §28.

## Граница
- Представление только **читает** состояние матча и поток событий. Управление просмотром (скорость, пауза, точка зрения, камера) на матч не влияет. Тест `WatchingDoesNotChangeTheMatch_WhateverTheFrameSizesAndSpeeds`: «просмотренный» матч с рваными кадрами, сменой скорости, паузами и шагами даёт ту же контрольную сумму событий, что и прогон без показа.
- Логика без Unity лежит в `src/Dynasty.Presentation` (netstandard2.1, C# 9) и покрыта тестами .NET. Unity только рисует.

## Dynasty.Presentation
| Тип | Назначение |
|---|---|
| `MatchClock` | Реальное время кадра → целые тики: скорость ×1…×64, пауза, шаг на один тик, доля до следующего тика (`Alpha`) для интерполяции. Если кадр долгий, лишние тики отбрасываются, а не копятся. |
| `MatchFrame` | Неизменяемый снимок одного тика глазами точки зрения (`Observer`, `Dawn`, `Dusk`): видимые живые юниты (`UnitFrame`: позиция, HP, мана, уровень, высота, кто видит, невидимость), призраки (`GhostFrame`: последняя известная позиция вражеского героя), снаряды, время суток, счёт, победитель. Взгляд команды строится по её туману войны и не раскрывает скрытого (спека §13.2). |
| `MatchSession` | Матч с ИИ + часы + два последних кадра (`Previous`, `Current`) + интерполированные позиции (`Poses`) + лента публичных событий (`TakeFeed`: убийства героев, строения, босс, байбэки, день и ночь, конец матча). |
| `MatchStatistics` | Цифры аналитика (§13.3): KDA, добивания и denies, уровень, net worth, заработанное золото, GPM и XPM, урон по героям, лечение, варды, смоки, байбэки; поминутно — золото команд (точно, из событий) и опыт (снимок при обновлении: опыта нет в событиях). Это знание наблюдателя: во взгляде команды HUD прячет экономику соперника. |
| `MapLayout` | Статичная карта во float: размер, деревья, линии, плато, фонтаны, лагеря, логово босса. |
| `DeterminismProbe`, `DemoMatch` | Демо-матч и его контрольные суммы для сверки рантаймов (D-029); `DemoMatch.Rosters` — две оригинальные демо-команды (Northwind, Ember Pact) с детерминированными пулами и сигнатурными героями. |
| `DraftWatch` | Драфт ИИ против ИИ по шагам в заданном темпе: последний выбор и его разбор (`DraftCandidate`), альтернативы, планы обеих команд; `StartMatch` запускает матч с героями на позициях и стратегиями из планов. |

## Unity-проект `unity/DotaDynasty`
Unity 6000.3.27f1, URP 17.3. Ядро — DLL из `tools/sync-unity.ps1` (в git не хранятся). Сцена `Assets/Dynasty/Scenes/Match.unity` пустая: `ViewerBootstrap` создаёт `MatchViewer` при загрузке (D-030).

- **3D-трансляция** (`WorldView`, `BroadcastCamera`): земля 100×100 м (100 единиц карты = 1 м), деревья, линии, плато, фонтаны; юниты-примитивы в цветах команд (герои — капсулы, крипы — кубы, башни — цилиндры, древний — большой куб, босс — фиолетовая сфера, руны — голубые сферы, варды — маленькие сферы); полоски HP смотрят в камеру; снаряды; свет дня и ночи. Камера: WASD или правая кнопка мыши — сдвиг, колесо — зум, `F` — следовать за героем.
- **Tactical 2D** (`TacticalMap`): карта рисуется в текстуру один раз; каждый кадр — юниты, строения, варды, кольца последних известных позиций, снаряды. Во взгляде наблюдателя — мини-карта в углу, `M` — во весь экран.
- **HUD** (`Hud`, IMGUI — заглушка): счёт, время, день или ночь, скорость, точка зрения; лента событий; `Tab` — таблица аналитика.
- **Управление:** `Space` пауза, `.` шаг, `1`–`6` скорость, `V` точка зрения, `M` 3D или тактика, `F` следовать, `Tab` таблица.

## Экран драфта (`DraftScreen`)
Запускается первым (`-dynasty-skip-draft` — сразу демо-матч). Без `-dynasty-seed N` обычный запуск берёт случайный seed (автоматические скриншоты — seed 1); seed виден на экране драфта и в HUD, по нему матч можно повторить. По бокам — баны и пики команд, после драфта — позиции, игроки и их мастерство, план (архетип, минута пика силы, сильные и слабые стороны). В центре — последний выбор с разбором (комфорт, состав, контрпики, синергия, мета; для бана — комфорт соперника, угроза, мета), альтернативы и доступные герои. `Space` — пауза, `1`–`3` — темп, `Enter` — до конца драфта, затем старт матча. Скриншоты: `-dynasty-draft-screenshots DIR`.

## Проверки
- .NET: `Dynasty.Presentation.Tests` (часы, кадры и туман, сессия, лента, интерполяция, статистика, раскладка карты, замер детерминизма).
- Unity EditMode: `DeterminismTests` — демо-матчи в Mono совпадают с эталоном .NET.
- Unity IL2CPP: `BuildTools.ProbeIl2Cpp` собирает Windows-плеер, запускает его в batchmode и сверяет суммы с эталоном.
- Unity PlayMode: `ViewerTests` — на 3D-доске ровно юниты текущего кадра в каждой точке зрения (проверено саботажем).
- Визуально: `DotaDynasty.exe -dynasty-screenshots DIR` сохраняет 3D и тактику для трёх точек зрения.

## Ограничения
- Заглушечная графика без анимаций, эффектов способностей и моделей; IMGUI вместо полноценного интерфейса.
- Нет зон обзора на тактической карте и тумана в 3D (скрытое просто не рисуется); нет авто-режиссёра камеры.
- Нет реплеев с перемоткой (§13.4) — этап 12.
- Unity MCP пока не установлен: для работы через batchmode он не понадобился.
