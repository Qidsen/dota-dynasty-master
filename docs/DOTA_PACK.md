# Пак правил Доты (этап 06.7)

**Цель (решение пользователя, 2026-10-26):** игра загружает героев, способности, таланты, Аганим-шард и скипетр, предметы и правила опыта из файла пака правил (спека §27, Gameplay Ruleset Pack). Пак Доты — главная цель: на нём настраиваются ИИ и экономика, на нём меряется реализм и идёт приёмка. Вымышленные герои — минимальная база поставки и тестовые фикстуры движка.

**Патч:** 7.41f. **Источник данных:** открытый набор `odota/dotaconstants` (MIT, данные из файлов игры), закреплённый коммит `5c0242df9057848fa2036ca3fafe9f2bd4508163` (2026-10-12). Сверено с примечаниями 7.41f на Liquipedia (цены Daedalus, Dragon Lance, Heart, Octarine Core, Heaven's Halberd; броня Bane; прирост интеллекта Batrider; мана-реген Essence Distiller). Статы юнитов-призывов, которых нет в `dotaconstants`, — из файла игры `npc_units.txt` (зеркало SteamDatabase/GameTracking-Dota2, закреплённый коммит `3f630cc`, D-049). Механики, которых нет в данных (формулы атрибутов, опыта, классов атаки), сверяются с Liquipedia и записываются в `docs/DOTA_BENCHMARKS.md`.

**Правовая граница (спека §27.3):** пак генерируется локально инструментом из репозитория и в репозиторий не попадает; в поставке — только формат, импорт и генератор.

## Сборка и формат
- Сборка пака: `dotnet run --project tools/Dynasty.DotaPack` → `packs/dota-7.41f.json` (папка `packs/` в `.gitignore`; данные `dotaconstants` кэшируются в `packs/cache/`).
- Загрузка: `Dynasty.Content.RulesetPack.Apply(базовые правила, json)` — пак заменяет героев и правила героев и, если они в нём есть, карту, типы юнитов и строений, волны, руны и босса; остальное (драфт, смена дня и ночи) — из базовых правил. Ошибки — `RulesetPackException` с путём к полю (`heroes[1].agility: …`). JSON читает собственный парсер `Dynasty.Core.Json` (без зависимостей; числа — точно из десятичного текста, без плавающей точки).
- Проверка на матчах: `MATCHLAB_PACK=packs/dota-7.41f.json dotnet run --project tools/Dynasty.MatchLab -c Release -- quality 32` (зеркальный состав Juggernaut, Lion, Shadow Fiend, Mars, Earthshaker; другой состав — `MATCHLAB_HEROES=antimage,necrolyte,zuus,doom_bringer,bounty_hunter`: керри, саппорт 5, мид, оффлейн, саппорт 4).
- Формат `dynasty.ruleset-pack`, версия 1: `id`, `version`, `name`, `provenance`; `heroRules` (необязательно: `xpForLevel`, `xpShareRadius`, `heroKillXpBase`, `heroKillXpPerLevel`, `heroKillXpPercentOfVictim` — остальное из базы); `heroes[]`: `id`, `name`, `roles`, `attackType` (`melee`/`ranged`), `primaryAttribute` (`strength`/`agility`/`intelligence`/`universal`), `strength`/`agility`/`intelligence` и `…Gain`, `baseHealth`, `baseHealthRegen`, `baseMana`, `baseManaRegen`, `baseArmor`, `magicResist`, `attackDamageMin`/`Max`, `attackRange`, `projectileSpeed`, `baseAttackTime` и `attackPoint` (секунды), `baseAttackSpeed`, `moveSpeed`, `dayVision`, `nightVision`, необязательные `abilities`, `itemBuild`; `unitTypes[]` (добавляются к базовым: `id`, `health`, `armor`, `moveSpeed`, `visionRange`, необязательные атака, `trueSight`, `invisible`, `attackClass`, `bounty`); `abilities[]` (заменяют базовые: `id`, `name`, `targeting`, `targetTeam`, `castRange`, `castPoint`, `cooldown[]` и `manaCost[]` по уровням в секундах и мане, `requiredLevels[]`, `effects[]` — дерево эффектов движка: `damage` (необязательный `scaling`: `targetMaxHealthPercent`, `targetMissingHealthPercent`, `targetCurrentHealthPercent`, `targetMaxManaPercent`, `targetMissingManaPercent` — тогда `amounts` в процентах, дробных), `manaBurn` (`amounts` — мана, `damagePercent` — доля сожжённого как урон), `heal`, `modifier`, `area`, `dash`, `knockback`, `summon`, `teleport`, `dispel`, `projectile`; `passive[]`; модификатор может наносить `damagePerSecondMaxHealthPercent`); `items[]` (заменяют базовые: `id`, `name`, `cost`, `components`, `bonuses` — модификатор, `active`, `charges`). Неизвестное поле — ошибка.
- **Карта (`map`, необязательно; D-053):** пак со своей картой заменяет карту базы целиком. `width`, `height`, `navCellSize`, `navClearance`; `terrain` — карта по клеткам навигации, ряды снизу вверх (y = 0 первым): `columns`, `rows`, `walkable` (base64, бит на клетку, младший бит байта первым), `visionBlockers` (то же), `levels` (base64, байт на клетку — высота шагами по 128), `treeSize` (128: дерево закрывает квадрат 128×128 вокруг себя для ходьбы и обзора), `trees` — плоский список `[x, y, x, y, …]`; `lanes[]`: `id`, `dawn` (путь Dawn от своей базы, плоский список точек), `dusk` (свой путь Dusk от своей базы; без него Dusk идёт по `dawn` назад); `structures[]`: `id`, `team` (`dawn`/`dusk`), `type`, `x`, `y`, `ancient`, `protectedBy`, `vulnerability` (`anyProtectorDestroyed` — по умолчанию, `allProtectorsDestroyed`, `never`), `barracksLane`; `fountains[]`: `team`, `x`, `y`, `radius`; `camps[]`: `id`, `x`, `y`, `creeps[]` (`creep`, `count`), `firstSpawn`, `respawn`, `leashRadius`, `alignedToClock`. С картой пак обязан поставить логово босса (`boss.position`, `boss.leashRadius`) и может вводить новые типы строений (`structureTypes`; без своей карты — только заменять типы базы и добавлять фонтан). Тип строения-барака: `upgradesCreeps` — какие крипы врага на его линии он улучшает при своей гибели. Волны: `superUpgrades` и `megaUpgrades` — `[{ "from", "to" }]` (мега — на всех линиях, когда пали все бараки врага).
- **Карта Доты 7.41f** собирается генератором (`tools/Dynasty.DotaPack/DotaMap.cs`) из `sikleq/Oldgrowth` на закреплённом коммите `2de3a39b` (версия `7.41f-1007`: файл `maps/dota.vpk` клиентского обновления 2026-10-07, последнего внутри 7.41f): сетка 320×328 клеток по 64 (20 480 × 20 992), координаты Доты сдвинуты на (+10 240, +10 752); 2475 деревьев, 382 клетки блокеров обзора, высоты 0–12; по 11 башен, 6 бараков (ближний и дальний на линию), 7 чучел, древний и фонтан на сторону; пути линий — свои у каждой стороны (цепочки `path_corner` от спаунеров); 28 лагерей (по 14 на половину карты: 3 малых, 7 средних, 3 больших, 1 древний); точки рун силы и богатства; верхнее логово Рошана. Генератор проверяет, что углы путей, лагеря и руны стоят на проходимой земле.

## Объём данных (dotaconstants, 7.41f)
- 127 героев: атрибуты и прирост, базовые HP, мана, реген, броня, магическое сопротивление, урон, BAT, скорость атаки, точка атаки, дальность, снаряд, скорость, обзор; роли.
- Около 790 способностей героев (в среднем 6,2 на героя, с врождёнными) и около 1000 талантов (только текст: «+X …»); у способностей — поведение, цель, тип урона, кулдауны и мана по уровням, параметры (`attrib`: урон, длительность оглушения, радиус и ещё сотни разных ключей).
- Описания шарда и скипетра для каждого героя (текст; новая способность или улучшение существующей).
- 501 запись предметов: стоимость, компоненты и рецепты, статы (`bonus_strength`, `bonus_damage`, `bonus_attack_speed`, …), активные и пассивные эффекты (текст + параметры).
- Таблица опыта до 30-го уровня.

## Волны
0. **Фундамент** (сделано: атрибуты, JSON, формат и загрузка пака, генератор — 127 героев со статами и атрибутами, опыт до 30-го уровня; осталось: очки способностей и уровни талантов): атрибуты героев (сила, ловкость, интеллект, универсальный) и производные статы по формулам Доты; BAT и базовая скорость атаки; 30 уровней; очки способностей и уровни талантов; формат пака (JSON) и его загрузка в `RulesetContent`; генератор пака из `dotaconstants`; тесты формата на синтетическом паке; приёмка — на настоящем паке (без него падает с подсказкой, как его собрать).
1. **Предметы со статами** (сделано: 188 действующих предметов магазина — список с Liquipedia «Items», данные `dotaconstants`; статы по таблице ключей; компоненты; активки расходников — ТП, варды, Healing Salve, Tango, Clarity, Faerie Fire, Smoke; сборки героев из OpenDota itemPopularity без компонентов; всё не перенесённое — в `packs/dota-7.41f.coverage.txt`): атрибуты, урон, скорость атаки, броня, HP, мана, реген, скорость бега, магическое сопротивление; компоненты и рецепты; закупка ИИ.
2. **Способности** (в работе): таблица соответствий `tools/Dynasty.DotaPack/abilities.json` — структура каждой способности в дереве эффектов движка со ссылками на ключи данных (`$damage`, `-$slow`, `$attack_damage*4`), статус full или simplified с пояснением; врождённые — с признаком innate. **Правило:** числа — только из данных (генератор отвергает число, набранное в таблице вручную, кроме соглашений движка — D-049); если механику нельзя выразить без выдуманных чисел, способность остаётся «нет» (в отчёте покрытия). Движок дополнен механиками Доты: процент входящего урона и урона атаки, уклонение, эффекты при атаке с шансом, ауры, иммунитет к дебафам, врождённые способности, сплеш, барьеры, «не может умереть», бафы на следующую атаку, сжигание маны с уроном, урон в процентах от максимального, недостающего и текущего HP и от максимальной и недостающей маны цели, урон со временем в процентах от максимального HP, восстановление маны (`restoreMana`), эффекты при атаке «после N атак» (`onHitAfterAttacks`) и эффекты на каждую N-ю полученную атаку (`whenAttacked`, `whenAttackedEvery`); волна 4а: накапливаемые модификаторы (`stacking`, `maxStacks`: каждое наложение — ещё заряд, все заряды делят одну длительность), урон за заряд модификатора кастующего на цели (`perTargetStack`), урон в процентах от атаки и атрибутов кастующего (`casterAttackDamagePercent`, `caster…Percent`), атака способностью (`attack`: процент урона атаки со всеми эффектами при атаке; у дальних — мгновенно, без снаряда), эффекты на самого кастующего (`onCaster`), перезарядка срабатывания эффектов при атаке (`procCooldown`) и шанс эффектов на полученную атаку (`whenAttackedChance`); волна 4б: зоны на земле (`zone`: радиус, команда, длительность, период — каждый период эффекты на юнитов внутри; зона стоит на месте), притягивание к кастующему или к точке (`pull`), `attack` без `amounts` — обычная атака (100 %, соглашение движка), ссылка `$cd` — перезарядка самой способности (для `procCooldown`). Числа, записанные строкой («100»), генератор отвергает так же, как набранные вручную. Триггеры модификатора: при касте (`onCast`), при убийстве (`onKill`, цель — убитый), при смерти носителя (`onDeath`, цель — убийца); эффекты при атаке только по героям (`onHitHeroesOnly`); зона только по героям (`heroesOnly`). Атака, сделанная эффектом при атаке, не запускает этот же эффект снова (нет цепочек Time Lock). Иллюзии (`illusion`: число, длительность, модификатор урона наносимого и получаемого) — копии героя с его текущими HP, бронёй, сопротивлением, скоростью и атакой. Заряды способностей (`charges`, `chargeRestore` по уровням: каст тратит заряд, заряд возвращается через время восстановления, перезарядка способности разделяет касты, заряды восстанавливаются и у мёртвого героя). Атака по нескольким целям (`extraTargets`, `extraTargetRadius`, `extraTargetDamagePercent`: ближайшие к атакующему враги получают долю атаки с её эффектами, сразу). Иммунитет к физическому урону (флаг `physicalImmune`), страх (`feared`: герой убегает от источника, не атакует и не кастует; крипы только перестают атаковать) и провокация (`taunted`: герой атакует источник, не кастует; крип бьёт источник), эффекты при убийстве только за героев (`onKillHeroesOnly`). Баф на N атак (`attackCharges`), условие «только если цель — герой» (`ifHero`), добивание ниже порога (`execute`, без брони и барьеров, но не сквозь «не может умереть»), дополнительные цели от края дальности атаки (`extraTargetRadiusFromAttackRange`), с шансом (`extraTargetChance`) или с долей урона, заданной снижением (`extraTargetDamageReduction`). Проценты скорости и шансы (`moveSpeedPercent`, `critChance`, `evasion`, `onHitChance`, `whenAttackedChance`) принимают дробные значения (33,33; 2,5) — в правилах это сотые доли процента; целый шанс бросается как раньше (из 100), дробный — из 10000. Заряженный баф считает атаки начиная со следующей после выдачи, удары по дополнительным целям его не тратят; `extraTargets` ≥ 20000 — все враги в радиусе. Возрождение (`revives`: вместо смерти герой сразу возвращается с полными HP и маной, эффекты `onDeath` этого модификатора срабатывают при возрождении, `procCooldown` — его перезарядка; убийство не засчитывается). Зона без периода — постоянная (как аура на земле): только модификаторы с длительностью, обновляются с каждым обновлением аур (генератор принимает у них `duration: 1`). Врождённые строятся с одним уровнем (значения по уровням — первое) и могут объявлять призываемых юнитов.
2а. **Активные и пассивные свойства предметов** (в работе): таблица `tools/Dynasty.DotaPack/items.json` в том же формате и по тем же правилам, что и `abilities.json` (числа — только ссылки на ключи данных предмета): `passive` — шаблон модификатора, который вливается в бонусы предмета (Bash, Cleave, ауры), `active` — способность `item_<предмет>` с одним уровнем (BKB, Blink). ИИ использует активные предметы так же, как способности героя.
3. **Таланты, шард, скипетр** (перенесены числовые улучшения, B-137). Данные — файлы героев игры по закреплённому коммиту GameTracking (сборка 6962): привязки `"special_bonus_…" "+75"` в значениях способностей; формы операций проверены на текстах талантов: `+n`/`-n`/`n` — прибавить, `=n` — заменить, `xn` — умножить, `n%` — увеличить на процент, несколько значений — по уровням; привязки аспектов (`special_bonus_facet_*`, аспекты убраны в 7.41) не используются. Генератор строит варианты способности для всех сочетаний её улучшений (до пяти), вариант без изменений перенесённой части не пишется; дробные значения целых полей округляются с записью в отчёт (B-135). Значения общих талантов — `npc_abilities.txt` игры. Порядок талантов в ступени (какой ИИ берёт первым): чаще выбираемый в про-матчах 7.41f (OpenDota explorer, не меньше 20 матчей героя), иначе в матчах Divine–Immortal (STRATZ API, ключ — `packs/stratz.token`, не коммитится), иначе сборка ботов Valve. Правила 7.40+ (проверено по патчноутам 7.40 и Liquipedia, уточнено у владельца проекта): таланты — отдельными очками талантов на уровнях 10, 15, 20, 25, 27, 28, 29, 30, не тратят очки навыков; на 10/15/20/25 — один из двух талантов ступени, на 27–30 — пропущенные, по порядку ступеней; очко навыка, которое некуда вложить, автоматически уходит в +2 ко всем атрибутам (7 уровней). Формат: `heroRules.talentPointLevels`, `attributeBonusLevels`, `attributeBonusPerLevel`, `skillPointLevels` (по умолчанию — каждый уровень); у героя `talents` (`id`, `name`, `level`, необязательный `bonus` — постоянный модификатор); у способности `variants` (`upgrades` — id талантов, `scepter`, `shard` — и полное описание способности с этими улучшениями); у предмета `upgrade` (`scepter`/`shard`, пока предмет у героя). Способность берёт вариант по набору улучшений героя.
3. **Таланты, шард, скипетр, врождённые:** сначала статовые таланты, затем изменения параметров способностей, затем новые способности.
4. **Уникальные механики** волнами, начиная с самых пикуемых героев про-сцены (иллюзии, превращения, Invoker, Meepo и т. д.).
5. **Сборки и драфт:** сборки предметов и способностей героев, профили для драфт-ИИ; настройка ИИ и экономики по ориентирам OpenDota на паке.

Каждое упрощение — в `docs/BACKLOG.md`.
