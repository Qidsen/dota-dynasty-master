# Дота 7.41f в игре: что есть и чего нет

Сводка по всем системам Доты: что уже перенесено в движок и пак, что упрощено, чего нет. Обновляется при каждом
изменении. Подробности по способностям и предметам — в отчёте покрытия, который генератор пишет рядом с паком
(`packs/dota-7.41f.coverage.txt`, не коммитится); формат и правила переноса — `docs/DOTA_PACK.md`; всё отсутствующее
и упрощённое — в `docs/BACKLOG.md` с ID.

**Правило:** правила игры сверяются с самым последним состоянием игры — 7.41f со всеми буквенными патчами и сборками после него (файлы игры по самому свежему коммиту GameTracking, dotaconstants, патчноуты 7.41–7.41f, Liquipedia); источник по более старому патчу годится, только если правило в 7.41–7.41f не менялось. Иначе — уточнять у владельца проекта; правила из источников 7.41 (данные dotaconstants и файлы игры по закреплённым
коммитам, патчноуты dota2.com, Liquipedia) или уточняются у владельца проекта — не по памяти.

Статусы: **есть** — работает как в Доте; **частично** — работает с упрощениями (они в заметках и в бэклоге);
**движок готов** — механика есть, данных в паке ещё нет; **нет** — не начато.
