## Известные проблемы
- Пуш-план меняет поведение, но строений пока берёт не больше: нужна настройка ИИ.
- Мета драфт-ИИ строится по профилям, а не по результатам симуляции (этап 07). Привычки соперника — только через пулы его игроков.
- Нет таймеров драфта и выбора стороны.
- Унаследовано: керри добивают мало, хайграунд чаще берут супер-крипы, строения не блокируют путь, графика заглушечная.
