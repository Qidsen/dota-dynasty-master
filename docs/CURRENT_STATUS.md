- **Этапы 00–05:** ядро, полный базовый матч, командный ИИ, обзор, Unity-просмотрщик (3D + Tactical 2D + HUD), 24 героя, драфт-ИИ, план драфта → стратегия в матче, экран драфта; детерминизм .NET / Mono / IL2CPP.

  - тренировки: недельный план, постепенный рост до потенциала, усталость и выгорание; усталость ухудшает игру;
  - демо-команды — настоящие игроки; матч после драфта играют они; в Unity — игроки на экране драфта и ники в таблице.
- Критерий этапа подтверждён приёмкой на зеркальных составах: сильные игроки выигрывают большинство матчей с любой стороны, лучше дерутся и фармят; замена одного игрока меняет участие его героя в драках (урон по героям в 2,7 раза). MatchLab `skill 17 7 16`: 14/16 побед с каждой стороны.
