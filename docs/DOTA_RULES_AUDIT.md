# Аудит общих правил движка против Доты 7.41f

Проведён 2026-10-27 по запросу владельца проекта («с головы не бери»). Проверялись общие правила, которые движок
применяет, когда играет на паке Доты: пак (`RulesetPack.Apply`, `src/Dynasty.Content/RulesetPack.cs`) заменяет только
героев, способности, предметы, призывов и часть правил героев (`xpForLevel`, `xpShareRadius`, `heroKillXp*`, очки
навыков и талантов). Всё остальное — бой, крипы, строения, карта, волны, лес, босс, руны, день и ночь, золото за
убийства, возрождение, выкуп, фонтан — пока берётся из базовых правил движка, поэтому расхождения ниже действуют и
на паке.

Источники:
- Liquipedia: Gold (с журналом изменений до 7.40), Experience, Attributes, Armor, Attack Damage, Buildings, Lane Creeps,
  Neutral Creeps, Roshan, Runes, Denying, Evasion, Version 7.41e/7.41f. Выгрузки — в рабочей папке сессии, часть через
  API Liquipedia 27.10.2026.
- Файл игры `npc_units.txt` (SteamDatabase/GameTracking-Dota2, закреплённый коммит).
- Поиск в вебе — помечен «WS».

Liquipedia ограничила частоту запросов, поэтому часть страниц (Movement Speed, Attack Speed, Magic Resistance,
таблица возрождения) прочитана только по выдержкам поиска.

**Следующий шаг:** правила переносятся в пак и в движок по этой таблице. Каждое исправление отмечается здесь как
исправленное, со ссылкой на коммит; всё ещё открытое — в бэклоге (B-133).

- Окно ассиста 10 с (`BaseContent.cs:74`): для золота и опыта в Доте важен радиус 1500, явного окна для счётчика ассистов не найдено.
