# Ориентиры по реальной Доте

Цели для реализма матча (этап 06.6): золото, добивания, убийства по позициям. Источник — публичный API OpenDota, 100 последних профессиональных матчей (собрано 2026-10-26, патч на тот момент). Скрипт: `tools/benchmarks/opendota_stats.py` (`python -I tools/benchmarks/opendota_stats.py out.json 100`, около 2 минут из-за лимита API; `--cached` — пересчитать по уже скачанному `out.json`). Опыт — `xp_t` OpenDota.

**Как считается.** «Золото» — `gold_t` OpenDota: всё заработанное к минуте, включая стартовое, пассивное и потраченное (близко к нетворсу, но без потерь на расходники и смерти). Позиции: мид — игрок центральной линии; на лёгкой линии позиция 1 — кто заработал больше к 10-й минуте, позиция 5 — второй; на сложной так же 3 и 4. Команды с нестандартной раскладкой (трилайн, лес) пропущены: 17 из 200.

## Механики Доты, сверенные для реализма

Источник — Liquipedia (через API `liquipedia.net/dota2/api.php?action=parse&page=…`, 2026-10-26): страницы «Attack Damage», «Buildings», «Lane Creeps», «Neutral Creeps».

- **Классы атаки** (7.31+): герои по зданиям 50%; ближние крипы (Runty) по героям 75%, по зданиям 70%; дальние (Piercing) по героям 50%, по крипам 150%, по зданиям 35%; осадные и здания (Reinforced) по зданиям 250%; прочие юниты по зданиям 70%. В ruleset — D-043.
- **Башни:** T1 1800 HP, броня 12, урон 88–92 (100 в секунду); T2/T3 2500 HP, броня 16, 170–174 (191 в секунду); T4 2600 HP, броня 21. У T2+ защита от бэкдора (−50…75% урона, если рядом нет вражеских крипов). Награда за T1: 90 золота каждому в команде, добившему ещё около 120.
- **Крипы линий:** волна каждые 30 с: 3 ближних + 1 дальний; осадный — каждая 10-я волна (с 5:00). С 15:00 — 4 ближних, с 30:00 — 5 ближних и 2 осадных, с 40:00 — 2 дальних, с 45:00 — 6 ближних. Каждые 7:30 улучшение: ближний +12 HP, +1 урона, +1 золота; дальний +12 HP, +2 урона, +3 золота, +8 опыта.
- **Лес:** на сторону 2 малых (около 58 золота, 1350 HP на лагерь), 5 средних (около 80, 1900), 5 больших (около 100, 1900), 2 древних (около 164, 3500). Спавн каждую минуту по часам с 1:00, если в зоне лагеря нет юнитов. В ruleset — D-044 (12 лагерей, без блокировки юнитами).
