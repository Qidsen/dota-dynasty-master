# Ориентиры по реальной Доте

Цели для реализма матча (этап 06.6): золото, добивания, убийства по позициям. Источник — публичный API OpenDota, 100 последних профессиональных матчей (собрано 2026-10-26, патч на тот момент). Скрипт: `tools/benchmarks/opendota_stats.py` (`python -I tools/benchmarks/opendota_stats.py out.json 100`, около 2 минут из-за лимита API).

**Как считается.** «Золото» — `gold_t` OpenDota: всё заработанное к минуте, включая стартовое, пассивное и потраченное (близко к нетворсу, но без потерь на расходники и смерти). Позиции: мид — игрок центральной линии; на лёгкой линии позиция 1 — кто заработал больше к 10-й минуте, позиция 5 — второй; на сложной так же 3 и 4. Команды с нестандартной раскладкой (трилайн, лес) пропущены: 17 из 200.
